# 출고 진척 현황판

WHOUT 출고 실적 엑셀을 올리면 USE(건)·매장(pcs)의 당일/누적 주문·출고·결품·잔여, 일자별 계획 대비 실적, 미출고(이월·장기 잔여·선입선출)를 보여주는 정적 페이지입니다.

## 사용
1. 페이지를 열고 비밀번호를 입력합니다.
2. **파일 올리기** 탭에서 WHOUT_RSLT_ORD_*.xlsx 를 올립니다. (시트가 여러 개면 원본 시트를 자동으로 찾습니다)
3. **실적 조회** 탭 상단에서 행사명·기간을 정하고, ③ 표에 일자별 계획을 입력합니다. (엑셀에서 계획 열을 복사해 첫 칸에 붙여넣으면 아래로 채워짐)

## 데이터
- 엑셀은 브라우저 안에서만 읽고 어디로도 전송하지 않습니다.
- 집계값·계획·행사명은 각 사용자의 브라우저(localStorage)에만 저장됩니다. 다른 사람·다른 PC와 공유되지 않습니다.
- 이 저장소에 엑셀 파일을 올리지 마세요. (.gitignore 로 막아 두었습니다)

## 비밀번호
브라우저에서 확인하는 가림막입니다. 페이지 소스를 볼 수 있는 사람은 우회할 수 있으니, 이 페이지에 민감한 값을 직접 넣지 마세요.
